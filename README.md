

\# Student Management System SQL Project



\## About the Project

This project manages student information using SQL and MySQL.



\## Objectives

\- Store student details.

\- Manage department information.

\- Store course details and fees.

\- Record student enrollments and marks.

\- Retrieve useful information using SQL queries.



\## Database Name

student\_management\_db



\## Tables

1\. departments

2\. students

3\. courses

4\. enrollments



\## SQL Concepts Used

\- CREATE DATABASE

\- CREATE TABLE

\- INSERT INTO

\- SELECT

\- WHERE

\- JOIN

\- GROUP BY

\- Aggregate functions such as MAX() and AVG()

\- Primary Keys and Foreign Keys



\## Tools Used

\- MySQL Server

\- MySQL Workbench

\- SQL



\## How to Run

1\. Open MySQL Workbench.

2\. Connect to your MySQL Server.

3\. Open and execute schema.sql.

4\. Execute insert\_data.sql.

5\. Open queries.sql and run the required queries.
